About STINGML: For the classification model, we employed 492 active STING inhibitors and 523 STING agonists. The dataset for this study was compiled through an extensive literature review and data collection from public chemical databases (ChEMBL and BindingDB), resulting in 492 sets of pIC50 data for STING inhibitors. The machine learning-based STING classification model achieved an accuracy of 0.985, while the STING inhibitor activity prediction model demonstrated strong predictive performance with an R² of 0.826, MAE of 0.357, and RMSE of 0.452.

Requirements: Python 3.9.12 Scikit-learn Pandas
